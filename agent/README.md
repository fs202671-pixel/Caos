# agent

Camada da IA principal.

Responsável por interpretar o usuário, adaptar comportamento por modo, gerar respostas, planejar ações e propor mudanças.

## Modos iniciais

- Chat
- Código
- Projetos
- Memória
- Imagem
- Voz
- Automação
- Dev Mode

## Limite

O agent não executa ações críticas diretamente. Ele gera ações estruturadas para o runtime validar.
