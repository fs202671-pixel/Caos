# memory

Camada de memória do Caos.

## Tipos

- Curto prazo: contexto da sessão atual.
- Longo prazo: dados persistentes do usuário e do sistema.
- Evolução: histórico de versões, testes e aprendizados controlados.

## MVP

A primeira versão usa memória local simples. Depois evolui para busca semântica, RAG e integração com backend local.
